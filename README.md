# WorldBuilder Demo

Twelve scenes built by [WorldBuilder](https://github.com/AdamRolander/WorldBuilder) from single
photos, viewable in a browser or a VR headset with nothing to install.

Live at https://adamrolander.github.io/worldbuilder-demo/

Each scene folder holds the viewer WorldBuilder generates (`index.html`), the lite scene
(`scene_lite.glb`), the placement fixes made in the viewer (`edits.json`) and the photo's point
cloud (`scene_points.json`). Photos are from Unsplash; credits are on the landing page.
